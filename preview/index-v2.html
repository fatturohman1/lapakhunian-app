Referensi v2 — Fusion

Kombinasi 2 referensi: Homey Real Estate Kit (font Lato, CTA pill, bottom-nav lingkaran tengah, search card lokasi/harga/tipe, filter sheet, light + dark) × Warna web asli LapakHunian — Material 3 hijau: primary #006d31, container #15a851, ink #0d1c2d, bg #f8f9ff, error #ba1a1a.

Light & Dark

Klik tombol Dark Mode di atas — semua layar ikut berubah (token CSS, bukan screenshot). Dark mode pakai #5edf80 (inverse-primary web) sebagai brand, teks CTA #003313 — sesuai pasangan M3 di web.

Interaktif

  • Tab atas = ganti layar (24 layar)
  • Klik kartu/tombol = navigasi + toast
  • Icon slider di Home/Jelajah = filter sheet
  • Kirim pesan di thread jalan beneran
  • Bookmark/heart bisa di-toggle

Catatan

File referensi saja — tidak untuk implementasi. v1 (index.html) tidak diubah. Struktur layar sama dengan v1 + 1 layar baru Peta (scr-map, gaya map Homey). Warna diseragamkan dengan hously (src/app/globals.css).
